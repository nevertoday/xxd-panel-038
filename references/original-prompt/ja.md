# XXD Panel 038 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い被写体、輪郭、姿勢、物語上の関係性を抽出し、さらに写真の情緒、サブテキスト、隠喩を理解したうえで、温かみのあるレトロな手作りのパッチワークアップリケとして再構成します。元画像を機械的に複製せず、チェック柄の綿布、リネン、洗いをかけた粗い麻、パッチ布、縫い目を用いて、最も重要な形態と関係性を簡潔な布片にまとめます。元のものが一目で分かると同時に、写真の背後にある静けさ、寄り添い、距離、滞在、成長、帰属、偶然の出会い、時間感覚などの内面的な情緒を感じられるようにします。

構図では余白の芸術と視覚的な呼吸を強調し、要素を均等に敷き詰めません。被写体の重心、動きの方向、物語上の関係性に応じて、布片の大きさ、疎密、重なり、裁ち切り、境界越えを自由に配置し、主要な形態と大きな余白の間に緊張感のある関係を作ります。一部の枝葉、輪郭、人物の動き、器物の縁、景物は、パッチワークの領域から自然にはみ出させることができます。画面が枠で閉じ込められているのではなく、成長し、通り過ぎ、または続いているように見せます。余白は空白ではなく、距離、情緒、時間、想像を担う空間です。

固定したカラーチャートは設けません。上の写真から最も生命力があり、その精神的な気質を最もよく表す色を抽出し、癒やし系でヒューマニズムのある柔らかな布の配色へ適応的に変換します。元画像固有の寒暖関係と色彩のアイデンティティを保ち、適度に柔らげ、明るくし、調和させ、全体を温潤で爽やか、親しみやすく、生活感のあるものにします。被写体には、より鮮明な重点色を1か所残すことができ、その他の色は柔らかく引き立てます。写真ごとに異なる色群を生み出し、固定的なベージュ、グレーブラウン、モランディ配色、意図的なエイジングは避けます。

本物の布目、繊維、ほつれた縁、縫い目、パッチ、交差するステッチ、わずかに不規則な継ぎ合わせを残し、手作業の痕跡が自然に見えるようにしますが、全体としてはハイエンドなエディトリアルデザインの抑制と精度を保ちます。レトロ感は素材と手仕事から生まれるものであり、汚れた色、黄ばみ、安っぽい古び加工によるものではありません。

文字は単に一文を置くのではなく、情緒と構図の一部になるべきです。元画像が直接語っていない情緒、動作、関係性、隠喩から、ユーザーが指定した対象言語で極めて短い単語または短句を抽出し、場所や物の名称だけを書くことは避けます。文字は、細線の刺繍、手縫いの縫い跡、または軽い手書きの形にでき、被写体の流れに沿わせたり、布片の縁に寄せたり、ネガティブスペースに隠したり、縫い目とともに続けたり止めたりして、図形と文字が一緒に読むリズムを形成するようにします。文字は少なく意味深くし、説明ラベルではなく、言い終えていない一言のようにします。

全体として、癒やし、温かさ、静けさ、人間味、生命力、余白、物語性のある視覚的な気質を表現し、ハイエンドな生活雑誌、インディペンデント絵本、現代テキスタイルアートを組み合わせた作品のようにします。被写体が人物、動物、植物、建築、器物、食べ物、交通手段、自然景観のいずれであっても、まず元画像が本当に何を表現しようとしているのかを理解し、そのうえで取捨選択、余白、継ぎ合わせ、文字組みの方法を決めます。子どもの工作教室のような印象、機械的な模写、均等な構図、意味のない装飾、テンプレート感は避けます。
