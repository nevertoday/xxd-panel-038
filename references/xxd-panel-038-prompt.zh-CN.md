# XXD Panel 038｜人文主义拼布贴画生产提示词

只处理当前新任务明确提供的这一张源照片。私下锁定身份、结构、姿态、方向、动作、功能、开口、关系、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

先理解照片没有直接说出的关系与情绪，再把必要形态重构为温暖的当代拼布贴画，由格纹棉布、亚麻、水洗粗麻、裁切布片、毛边、补丁和可见手缝线构成。

严格遵循这条因果链：读出未说出口的关系 → 保留三个辨识线索 → 删除字面场景 → 用源图色布片裁出必要形态 → 层叠、裁切、穿插并让局部越界 → 让针脚与毛边真实可见 → 用留白承载距离与时间 → 绣入一句未说完般的短语。

## 硬性视觉要求

- 保留至少三个源图线索，同时把人物、动物、器物、建筑或景观简化成有意义的布片形态。
- 真实呈现格纹棉布、亚麻、水洗粗麻、补丁布、毛边纤维、手缝针脚、交叉缝线与轻微不规则接合，并保持编辑设计的克制。
- 每张源图生成不同的温润、清爽、人文布艺色组；保留原图冷暖与一个鲜活焦点，不套米黄灰棕、莫兰迪或人为旧化。
- 以不对称、层叠、裁切、局部越界和大面积主动留白表达陪伴、距离、成长、停留、归属、偶遇或时间。
- 手工感来自纤维和缝制，不来自污渍、泛黄、脏旧或儿童手工课质感。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。从源图隐藏的情绪、动作、关系或隐喻提炼一个短语，而不是只写物名或地点。用目标语言中自然的细线刺绣、手缝线迹或克制手写，让文字在缝线与负空间中延续、停顿或隐藏。 用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标题、标签或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计和壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果。连贯套装始终共同参考原照片与同一张批准定调图，绝不串联衍生图。

拒绝：儿童手工课、整图机械临摹、平均铺满的被子格、固定米黄灰棕、假旧污渍、可爱贴纸、无纤维的印花模拟、无意义装饰与模板拼贴。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
